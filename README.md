An offline GTA 6 trophy guide and tracker covering all 55 PlayStation trophies: a saved checklist with localStorage persistence, filters by kind and grade plus search, a spoiler mode that hides story-trophy details until earned, a step-by-step roadmap to platinum, and export/import of your progress as JSON. Every trophy ships with a guide written in our own words, grounded in the official description and trailers, and an honest note that the game is unreleased so some details may change at launch.

## Run

```sh
node serve.ts
```

Then open http://localhost:8080 in your browser. No build step, no install — Node 22+ standard library only.
